# 常用官网

建议把常用入口放进同一个浏览器书签文件夹，并在手机安装 PolyULife 与 PolyU Library App。尽量从官方页面或自存书签进入，减少误点陌生短链的风险。

本文整理自公开官方入口与学生常见使用场景，**非 PolyU 官方出版物**。网址与功能可能调整，请以学校最新页面为准。

## 建议收藏的 10 个入口

1. **eStudent**：个人资料、选课、课表、考试表、成绩、毕业申请等  
   https://www38.polyu.edu.hk/eStudent/
2. **LEARN@PolyU**：课件、测验、作业提交、公告与课堂互动  
   https://learn.polyu.edu.hk/
3. **PolyU Connect Email**：学校正式邮件与 O365 入口  
   https://www.polyu.edu.hk/connectmail
4. **Academic Registry**：Student Handbook、Academic Calendar、选课、考试与表格  
   https://www.polyu.edu.hk/ar/
5. **Academic Calendar**：学期、Add/Drop、温习日、考试与出分日期  
   https://www.polyu.edu.hk/ar/students-in-taught-programmes/academic-calendar/
6. **PolyU Library**：OneSearch、myRecord、数据库、开放时间与服务  
   https://www.lib.polyu.edu.hk/
7. **Library iBooking**：预约小组房、线上会议房、电脑与设施  
   https://booking.lib.polyu.edu.hk/
8. **Campus Map**：官方校园地图  
   https://www.polyu.edu.hk/cdo/useful-information/campus-map/
9. **EasyPlanner**：辅助排课与比较组合；最终注册仍以 eStudent 为准  
   https://www38.polyu.edu.hk/easyplanner/
10. **IT Online Service Desk**：NetID、邮箱、Wi-Fi、软件或系统问题  
    https://www.polyu.edu.hk/itservicedesk

## 额外建议安装

- **PolyULife**：个人课表、考试表、缴费提醒与校园通知；重要结果仍回 eStudent 复核
- **PolyU Library App**：实时座位、预约与借阅提醒

具体功能以当前 App 版本为准。

## 一个任务该去哪个平台

按任务记平台，比背网站名称更省事：

| 我想做的事 | 去哪里 |
| --- | --- |
| 选课、退课、换班、查成绩 | eStudent |
| 看课件、交作业、做 Quiz、看老师公告 | LEARN@PolyU |
| 收正式通知、联系老师或学系 | PolyU Connect Email |
| 看个人课表、考试表和移动提醒 | PolyULife（重要结果回 eStudent） |
| 查书、论文、数据库、借阅记录 | PolyU Library / OneSearch |
| 看座位、预约小组房或线上会议房 | Library App / iBooking |
| 找教室 | Campus Map + POLY:U:WAY（先从 eStudent 复制准确场地） |
| 排多套课表方案 | EasyPlanner（注册与名额以 eStudent 为准） |
| 报名活动、订体育设施、约辅导或申请 Locker | POSS |
| NetID、Wi-Fi、邮箱或软件出问题 | ITS Online Service Desk；必要时到 M201 IT HelpCentre |

## 平台安全习惯

1. 优先从官方书签或 PolyU 页面进入，不随便点群聊里的缩短链接
2. 学校正式通知以 Connect Email 和官方系统为主，定期检查 Spam / Junk
3. 不要把 NetID、密码、验证码或预约账户借给他人

部分 Programme 可能还有部门专用系统，应单独记住，不要与全校基础入口混用。
