# 校园地图

理大主校园楼座和 Core 连接较多，单看一串场地代码很容易想当然。最稳妥的做法不是背完整地图，而是把「准确场地代码 → 楼座 / Core → 楼层 → 房间」逐项确认。

官方入口：

- Campus Map：https://www.polyu.edu.hk/cdo/useful-information/campus-map/
- POLY:U:WAY / Campus Wayfinding：以 ITS 当前页面与应用商店为准

## 第一次找教室：4 步法

1. 在 eStudent、PolyULife 或正式课表中复制完整场地代码，不要只看老师发在群里的简称
2. 打开官方 Campus Map，先找对应 Block 或 Core，再确认它是否位于主校园。多字母代码有时代表楼座连接区或特定区域，不要只按第一个字母猜
3. 使用 POLY:U:WAY 输入教室或建筑名称。官方服务可显示推荐路线、距离、步行时间和街景；Core P 附近也可能有导航终端
4. 开学前或第一天提前走一次：从你最常用的入口出发，记录最近楼梯 / 电梯、洗手间和下一节课的出口

### 特别注意非主校园场地

课表可能出现 Hung Hom Bay、West Kowloon 或其他教学地点。看到陌生前缀时，先查看课表场地说明和官方地图，不要默认都在红磡主校园内。

## 开学不迟到：三条路线策略

校园导航的目标不是找到「最短路线」，而是在拥挤、下雨、搭电梯和连续上课的情况下仍能稳定到达。

1. **标准路线**：POLY:U:WAY 推荐路线，平时使用
2. **高峰路线**：尽量少依赖热门电梯，优先使用熟悉的楼梯和 Core 连接
3. **雨天路线**：优先经过有盖通道，避免到达教室时全身湿透

### 开学周最有用的做法

1. 把第一周所有场地在地图上标记，先看相邻两节课之间是否跨楼座或跨校园
2. 连续课之间预留额外缓冲。导航显示的步行时间通常不包括等电梯、找门牌和拥挤
3. 到达楼层后拍下清晰门牌或走廊方向，但不要拍到他人的个人信息或课堂内容
4. 将常用地图页面收藏到手机，并保存一张离线截图，以备校园网络或 App 临时维护

### 不推荐的做法

不要只跟着人群走，也不要把「Core 字母」当作方向感的唯一依据。第一周多花 20 分钟建立自己的路线，之后一个学期通常都能受益。

施工、封路或入口管制会变化，出发前仍应看最新官方地图。
