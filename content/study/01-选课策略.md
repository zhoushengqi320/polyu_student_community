# 选课策略

选课当天才开始找课，最容易漏掉先修、Component 和毕业要求。下面把「注册前准备」「怎么排课更稳」和「Add/Drop 怎么操作」合在一起，方便一次读完。

本文为学生向整理，**非官方选课指引**。毕业要求、先修、名额与日期以 Programme Requirement Document、Student Handbook、Academic Registry 与 eStudent 为准。

## 选课前 30 分钟准备清单

适合在注册开放前快速过一遍：

1. 打开 Programme Requirement Document / Study Pattern，标出本学期必须修的核心课、GUR / CAR / SL，以及尚未完成的毕业条件
2. 在 eStudent 查看 Department Pre-assigned subjects、个人课表，以及 Personal Checklist 中的最早注册时间
3. 检查每门课的 Prerequisite、Exclusion、Programme restriction，以及是否只在特定学期开设
4. 为每门课选齐 LEC / TUT / SEM / LAB 等 Components，检查完整时间冲突，不要只看 Lecture
5. 用 EasyPlanner 或官方 Class Timetable 做组合，但把它当规划工具；最终名额、限制和注册结果以 eStudent 为准
6. 准备至少两门备选课和两个班别方案，并记录优先级；热门课满员时能立刻切换
7. 提前登录并检查 NetID、浏览器和网络；使用学校建议的浏览器，不要依赖未经允许的插件或自动化工具
8. 注册完成后确认 Confirmation Page 和 Reference Number，不要只看购物车或 EasyPlanner

毕业要求和先修链不确定时，应在注册前问 Programme Leader 或 Academic Advisor。社交平台上的「必选 / 避雷」不能代替 Programme 文件。

## 排课怎么平衡更稳妥

「课越集中越好」或「每天只上一两节最好」都不是通用答案。同时看学习强度、通勤、评估方式和生活节奏会更靠谱。

### 四条实用原则

1. **先排关键先修和只在某一学期开设的核心课**，再安排 CAR、SL 和 Free Elective。兴趣课不应挤掉毕业链条
2. **把重型课程分散**。多门编程、数学证明、实验或大型小组项目挤在同一学期，风险往往来自 Deadline 叠加，而不只是上课小时数
3. **一天连续上课要看场地距离和注意力**。三节相邻课如果跨楼座、没有吃饭和复盘时间，体验可能比四天分散上课更差
4. **给研究、实习、健身或社团留固定时段**，不要把空白全部填满；计划外任务一定会出现

### 早课与晚课

不要只看「老师评价」。回顾自己过去一个月真实的起床和专注时间；如果长期无法稳定早起，早课缺勤风险比想象中高。晚课则要考虑通勤、安全、晚餐和第二天早课。

### 如何使用学长学姐推荐

先问 Assessment、Workload、教学方式和先修基础，不只问「给分甜不甜」。老师、课程内容和考核每年可能变化；最终以当学期 Syllabus 和正式课程资料为准。

不要把未经证实的教师评价或「必给高分」结论当成事实发布或转述。

## Add / Drop：操作流程

Add/Drop 既是系统操作，也是用真实课堂信息修正课表的窗口。日期会随学期变化，**务必以当年 Academic Registry 与 eStudent Personal Checklist 为准**。下文以 2026/27 Semester One 公开日程为例，仅作时间线参考。

### 2026/27 Semester One 时间线（示例）

- 当前本科生 Subject Registration：2026-08-07 至 08-10
- 新生：2026-08-21 至 08-25
- 开学前 Adjustment：2026-08-28 至 08-30
- Add/Drop Period：2026-08-31 至 09-12

个人最早开始时间仍要看 eStudent Personal Checklist。

### Add 一门课

1. 进入 eStudent 的 Subject Registration，确认 Academic Year / Semester
2. 用 Subject Code 或 Programme / Category 搜索，阅读 Prerequisite、限制和班别信息
3. 选择 Subject Group，并把 LEC、TUT、SEM、LAB 等所需 Components 选齐；任一 Component 冲突都可能无法注册
4. Add to Cart → Proceed to Preview → Confirm
5. 完成后保存 Confirmation Page 和 Reference Number

### Drop 或 Change Class

1. 在 Shopping Cart / 已注册科目中选择相应操作，预览后 Confirm
2. Pre-assigned 科目可能不能直接 Drop，需向学系申请
3. 换 Tutorial 或 Seminar 时，优先使用 Change Class 或按官方流程重新选择 Components
4. 不要私下交换后以为系统会自动更新

### Waitlist

1. 若科目开放候补，选齐 Components 后加入 Waitlist 并 Confirm
2. 系统会显示实时位置；有空缺时按候补顺序自动注册，但仍要满足无时间冲突、学分上限等条件
3. 收到邮件后再核对课表
4. 候补第一也不保证一定有位

不建议采用高频刷新、插件、自动化抢课，或私下买卖 / 承诺交换名额。

## Add / Drop 两周怎么用

更稳妥的策略是先准备备选，再逐步收敛，而不是最后一天「赌一把」。

### 开始前

1. 准备 A / B / C 三套方案，记录每门课的 Subject Code、Group、Components、先修条件和冲突
2. 区分「必须本学期完成」「可延后」「纯兴趣」三类课程；关键先修链不要只看老师或上课时间

### 第一周

1. 参加第一节课，阅读 Syllabus，记录 Assessment 比例、小组项目、出勤、考试形式和主要 Deadline
2. 如果心仪课满员，立即加入官方 Waitlist 并保留可行备选；不要把候补位置当作已注册
3. 想换班时先确认新班有位且无冲突，再按系统流程 Change Class

### 第二周

1. 把所有课程的每周阅读、作业和项目时间放在同一张表里，判断是否过载
2. 截止前 48 小时尽量减少无备选的高风险操作；Drop 后名额可能立即被他人或候补系统接走
3. 最后一次 Confirm 后保存 Reference Number、截图和最终课表，并检查 LEARN 是否已同步

### 三个底线

1. 不把 EasyPlanner 当作最终注册结果
2. 不私下买卖或承诺交换名额
3. 不擅自 Drop 学系 Pre-assigned 的毕业必修
