# 宿舍指南：红磡与何文田、申请与保宿

理大宿舍由学生事务处（SAO）Residential Life 管理。名额有限，非本地生通常仍需同步准备校外租房方案（本站另有租房指南）。以下为流程框架，申请开放日、收费与结果公布时间请以 SAO 官网当年页面为准。

官方入口（简体页面可切换语言）：

- Hall Applications：学生事务处宿舍申请总览
- 联系邮箱常见为 student.halls@polyu.edu.hk（以官网为准）

## 宿舍介绍：怎么理解「两个区域」

同学常说的「两个宿舍」，大体对应：

### 红磡 Student Halls（Hung Hom）

- 距离主校区更近，步行通勤通常更方便
- 社区氛围浓，活动与朋辈支援较多
- 房间类型、设施、规章以红磡宿舍规条为准

### 何文田相关住宿（Homantin / 相关书院或宿舍安排）

- 相对离主校区更远，通勤多依赖地铁或校园交通安排
- 部分项目以书院（Residential College）形式运作，活动与住宿要求可能不同
- 规章可能单独成文（Homantin 相关 Residence Regulations）

不必纠结「一定要写成一篇对比表」：申请系统里你会勾选偏好，但偏好不保证获配。收到 offer 后再根据楼栋位置、室友安排与规章做决定。

### 申请前建议想清楚

1. 你能否接受「分到非第一志愿楼栋」
2. 预算是否覆盖全年宿舍费（含可能的按学期缴费）
3. 若落选，校外租房 backup 是否已在看

## 申请前必须完成：NetID

未开通 NetID，通常无法在 POSS 提交宿舍申请。

1. 到身份门户完成学生 NetID 注册
2. 若在傍晚后注册，预留系统生效时间（常见要等到次日）
3. 确认能登录 PolyU 邮箱（结果与缴费通知多发到这里）

## 线上申请流程（框架）

不同身份（本地新生 / 非本地新生 / 在读生 / 研究生）的开放时段不同，不要套用别人群里的截图日期。

### 通用步骤

1. 打开 SAO「Hall Applications」页面，确认你所属类别的申请期
2. 登录 POSS，进入 Student Halls 相关申请
3. 填写个人资料、住宿偏好、预期入住日期等
4. 提交后页面应出现确认编号（Reference No.）；同时查邮箱确认信
5. 在 POSS 的 Application Result 中自查，不要只等群消息

若提交后没有确认编号，立刻联系宿舍办公室，不要默认「系统卡住过几天就好」。

### 拿到结果之后

1. 在指定期限内于网上接受 offer；逾期通常视为放弃
2. 按邮件中的 Debit Note 缴纳宿舍费；逾期可能取消宿位
3. 阅读并遵守对应区域的宿舍规条
4. 按指引办理入住（Check-in）：携带证件、确认楼栋与钥匙/门卡手续

研究生新生：部分情况下需先完成课程注册，才可按约定入住；以 AR 与 SAO 说明为准。

## 入住当天实用清单

- 身份证明与学生证相关材料
- 录取 / 住宿 offer 电子或纸质凭证
- 基本床上用品（是否提供床褥以当年宿舍说明为准）
- 转换插头、延长线（注意宿舍用电安全规定）
- 少量现金/八达通，方便首日交通与采购

入住后尽快：连校园网、确认紧急联系人、了解楼层公共设施与垃圾分类规则。

## 保宿 / 续住流程

「保宿」通常指在读生申请下一学年继续住宿舍，而不是自动续约。

常见要点：

1. 在读生申请期往往早于新生（多在第二学期，具体看 SAO 公告）
2. 仍需在系统提交申请；过往住宿记录、违纪、欠费都可能影响结果
3. 结果同样通过电邮 / POSS 查询；接受 offer 与缴费环节与新生类似
4. 若计划毕业学期后退宿，留意 check-out 截止日期与房间检查要求

没有保宿成功不等于不能住香港：请尽早启动校外租房，避免开学周临时找房。

## 常见问题

### 偏好了 A 栋，会不会分到 B 栋？

会。偏好仅供参考，最终以分配结果为准。

### 非本地生是不是保证有宿舍？

不要默认保证。请按时申请，并同时准备租房方案。

### 迟交申请怎么办？

一般不接受逾期；个别情况即使接受也可能收取行政费。以当年政策为准，不要赌运气。

### 官方信息以哪里为准？

以 SAO Hall Applications 页面与你的 PolyU 邮箱通知为准。同学经验帖只能作参考，不能替代官方时间表与缴费要求。
