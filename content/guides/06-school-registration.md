# 学校注册：NetID、eStudent、选课与学生卡

学校注册不是「交一次表」就结束，而是一串账号开通、网上注册、选课与证件办理。不同课程（本科 / 授课型硕士 / 研究型）细节不同，请以 Academic Registry（教务处）发给你的注册指引为准。

## 注册前先做的三件事

1. 确认已按要求完成必要缴费或了解缴费截止日
2. 确认签证 / e-Visa 与入境安排不影响你按时报到
3. 保存好学生编号（Student ID / NetID 相关信息会出现在录取材料或后续邮件里）

## 开通 PolyU NetID

多数系统（电邮、eStudent、宿舍申请 POSS 等）都依赖 NetID。

建议顺序：

1. 打开学校身份门户（常见入口：PUsecure / Identity Portal，以官方邮件链接为准）
2. 选择学生身份完成 NetID Registration
3. 记下 NetID，并立刻设置强密码
4. 登录 PolyU 邮箱，之后几乎所有正式通知都会发到这里

注意：NetID 刚开通后，部分系统可能需要等待一段时间才能登录。若当天傍晚后才注册，次日再试宿舍申请等系统更稳妥。

## eStudent 注册

eStudent 是学生常用的网上服务入口，课程注册、成绩、部分个人资料与缴费查询常在此完成。

### 常见流程框架

1. 用 NetID 登录 eStudent
2. 按页面提示完成 Programme / Subject Registration（课程/学科注册）
3. 核对自己的课程、学期、注册状态是否正确
4. 若页面提示需上传文件、确认声明或预约面见，按截止日期完成

### 注册卡住时优先检查

- NetID / 密码是否可用，邮箱能否登录
- 是否仍有未缴清的必需账单
- 是否错过该课程的注册时段
- 邮件里是否要求先完成健康申报、签证信息或其他前置步骤

联系人通常写在注册邮件底部：Academic Registry 或你所属学院办公室。

## 选课准备

「注册成功」不等于「课表已排好」。本科与部分课程还需要在指定时段内选科 / Add-Drop。

建议你提前准备：

1. 阅读本专业的课程结构（Programme Requirement）与先修要求
2. 在 eStudent / 相关系统查看可选科目与时间冲突
3. 关注 Add / Drop 期限；逾期改课通常更麻烦
4. 热门课可能很快满额，准备 1–2 个备选组合

选课策略、GPA 规则等可再看本站「学习指南」模块；此处只强调：先看官方时间表，再进系统操作。

## 实体学生卡领取

实体学生卡（Student ID Card）一般用于闸机、图书馆、部分设施与身份核验。

### 领取前

- 确认已完成学校要求的注册步骤
- 按邮件指引准备证件照（规格以当年通知为准）
- 留意领取地点、开放时间与是否需要预约

### 领取时建议携带

- 身份证明文件
- 学生编号相关证明（录取信 / 电子凭证）
- 学校邮件中列出的其他材料

卡丢失后及时挂失/补办，具体收费与流程以学生事务或相关部门公告为准。

## 迎新活动

迎新（Orientation）可能由大学层面、学院、学生组织分别举办。

你可以这样安排：

1. 把官方迎新时间表放进日历，优先参加学院 / 课程强制场次
2. 宿舍迎新、社团招新可按精力选择参加
3. 保留重要场次的签到证明（若课程或宿舍有要求）

迎新不是可有可无的闲聊局：不少账号权限说明、校园地图、安全须知会集中在这一周讲完。

## 建议收藏的官方入口

- Academic Registry：课程注册、学期事务
- eStudent：日常学生系统
- Student Affairs Office（SAO）：宿舍、校园生活支援
- 你所属学院网页：专业课与迎新安排

日期、地点、材料清单每年可能变；本页提供流程骨架，最终以你收到的官方邮件为准。
